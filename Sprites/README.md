# Sprites

All Doods sprites live here. The game loads them by path.

- Pure white on transparent, no anti-aliasing. The game tints at runtime.
- Everything faces right. The game mirrors for left.
- Animations are one horizontal strip of equal frames, 24 FPS.
- Characters are 24x24 with the pivot at bottom center (x=12, y=24).

Generated by `Tools/build.py` (Python 3, Pillow, NumPy):

```bash
cd Tools && python3 build.py
```
